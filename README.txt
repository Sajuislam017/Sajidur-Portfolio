# MD. Sajidur Rahman — Premium Corporate Career Portfolio

## Included
- `index.html` — responsive one-page portfolio
- `assets/profile.jpg` — add your professional photo here (not included yet)
- `assets/MD_Sajidur_Rahman_CV.pdf` — add your latest CV PDF here

## Before publishing
1. Add a professional headshot named exactly `profile.jpg` inside the `assets` folder.
2. Add your latest CV PDF named exactly `MD_Sajidur_Rahman_CV.pdf` inside the `assets` folder.
3. Review the phone, email, LinkedIn and all CV details in `index.html`.
4. Check the page on mobile and desktop.

## Publish with GitHub Pages
1. Sign in at https://github.com/ and create a new public repository, for example `sajidur-portfolio`.
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the published URL to appear in the Pages section. It will usually look like:
   `https://YOUR-USERNAME.github.io/sajidur-portfolio/`

GitHub Pages is free for public repositories. A custom domain is optional and costs extra.
